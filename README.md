# Java-Language

A personal Java learning notes and practice collection covering Java fundamentals, object-oriented programming, exception handling, packages, data structures, algorithms, and problem-solving practice.

## Repository Contents

- `01_Basics` — Java fundamentals, variables, data types, conditions, loops, arrays, methods, and exception handling
- `02_Labs` — Practical Java laboratory exercises
- `03_OOPS` — Object-oriented programming concepts
- `04_DSA` — Data structures, algorithms, searching, sorting, strings, patterns, and LeetCode practice

## Purpose

This repository documents my learning journey and provides beginner-friendly Java examples and practice exercises.

It is intended for:

- Personal learning
- Portfolio presentation
- Reviewing Java concepts
- Practicing programming fundamentals
- Helping beginners understand basic Java topics

## How to Run the Programs

Open a terminal in the folder containing a Java file and compile it:

```bash
javac FileName.java
java FileName
```

Replace `FileName` with the name of the Java class you want to run.

Some programs require user input through the terminal.
