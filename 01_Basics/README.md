 #📚 01_Basics - Java Fundamentals

This folder contains core Java concepts, fundamental language syntax, and foundational programming logic built step-by-step.

---

## 📁 Topics & File Mapping

### 1. Fundamentals & Syntax
* **`A_firstjavacode.java`**: Environment setup verification and basic printing output.
* **`B_VariablesandDataTypes.java`**: Primitive data types, reference variables, and variable declarations.
* **`C_BasicPrograms.java`**: Simple mathematical operations and basic logical programs.
* **`D_input.java`**: User input handling using the `Scanner` class.
* **`E_Operators.java`**: Arithmetic, relational, logical, assignment, and bitwise operators.

### 2. Control Flow & Loops
* **`F_ConditionalState...java`**: `if`, `else-if`, `else`, and `switch` statements.
* **`G_forLoop.java`**: Iteration using fixed-range `for` loops.
* **`H_whileLoop.java`**: Condition-based iteration using `while` loops.
* **`I_doWhileloop.java`**: Post-condition iteration using `do-while` loops.

### 3. Modular Code & Structures
* **`J_Array.java`**: Single and multi-dimensional array declaration, initialization, and traversal.
* **`K_Functions.java`**: Method definition, parameters, return types, and scope.
* **`L_CommandLine.java`**: Handling command-line arguments via `main(String[] args)`.
* **`M_Patterns.java`**: Nested loop logic for printing stars, numbers, and matrix patterns.
